# Smart Money Dashboard

Static dashboard for tracking selected-house positioning signals, sector rotation, and 7-day price trends.

## Local Preview

```bash
cd outputs
./serve_dashboard.sh
```

Open:

```text
http://localhost:8080/13f_dashboard.html
```

## GitHub Pages

Use GitHub Pages with the `outputs/` directory as the published static site source.

Recommended settings:

- Source: GitHub Actions
- Entry point: `outputs/index.html`
- Dashboard: `outputs/13f_dashboard.html`

## Data Files

- `outputs/dashboard_data.json`: research signals
- `outputs/prices.json`: 7-day price data generated by `outputs/update_prices.py`

## Disclaimer

This dashboard is for research only and is not personalized investment advice.
